# Agentic Development Lifecycle

Use the skills that match the work. ADLC covers application development and
authorized defensive/security investigation. Six skills do not require six agents
or six phases for every task.

| Skill | Outcome |
| --- | --- |
| [Triage](factory-triage/SKILL.md) | Evidence-based disposition of an idea or issue |
| [Spec](factory-spec/SKILL.md) | A bounded, implementable accepted outcome |
| [Implement](factory-implement/SKILL.md) | A working candidate and relevant verification |
| [Review](factory-review/SKILL.md) | Independent assessment of the actual candidate |
| [Security](factory-security/SKILL.md) | Scoped findings, validation and remediation evidence |
| [Evaluate](factory-evaluate/SKILL.md) | An honest comparison of methods or configurations |

The project owns vision, architecture, coding/design standards and delivery rules.
Foundation adopts the method deliberately; Agent Ops coordinates work under the
owner's mandate. Research may finish with a recommendation to do nothing.
